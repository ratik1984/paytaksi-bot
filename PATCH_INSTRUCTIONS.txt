PAYTAKSI - DEBUG + PASSENGER NEARBY DRIVERS PATCH

Bu patch nə edir?
1) /api/passenger/nearby_drivers endpoint-i əlavə edir (Telegram auth tələb edir).
   - Query: lat, lon, radius_km (default 3), pt (Telegram WebApp token fallback).
2) /api/debug/nearby_drivers endpoint-i əlavə edir (Telegram auth BYPASS) amma yalnız DEBUG_KEY env var varsa.
   - Query: lat, lon, radius_km, debug_key
3) Passenger UI-də:
   - pt token URL-dən oxunur və API çağırışlarına əlavə olunur
   - "3 km sürücüləri göstər" düyməsi nearby drivers-ı xəritədə göstərir
   - "Sifariş et" düyməsi /api/passenger/create_ride-ə real POST edir

Quraşdırma:
A) Faylları kopyala:
- src/server.js  (mövcud faylın üstünə yazın)
- src/public/passenger/index.html  (mövcud faylın üstünə yazın)

B) Deploy/Restart et.

C) DEBUG endpoint istifadə etmək istəsən (opsional):
- Render Environment Variables -> DEBUG_KEY = uzun random bir string yaz.
- Sonra brauzerdə test:
  /api/debug/nearby_drivers?lat=40.4093&lon=49.8671&radius_km=3&debug_key=YOUR_DEBUG_KEY

Qeyd:
- /api/passenger/nearby_drivers brauzerdə işləməyəcək (Telegram auth var).
  Telegram WebApp içindən işləyir, çünki URL-də pt olur və frontend onu göndərir.
